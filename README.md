# 🔍 فاحص روابط Xtream Codes | Xtream Codes Link Checker

<div dir="rtl">

أداة ويب احترافية لفحص روابط اشتراكات **Xtream Codes IPTV** وعرض المعلومات الكاملة للاشتراك في واجهة عربية أنيقة وسريعة.

## ✨ المميزات

- 🎯 **فحص فوري**: الصق رابطك واحصل على النتائج خلال ثوانٍ
- 📊 **معلومات شاملة**: حالة الاشتراك، عدد الاتصالات النشطة، الحد الأقصى، تاريخ الانتهاء
- 📅 **حساب المدة**: عرض المدة الإجمالية للاشتراك والأيام المتبقية
- 📡 **إحصائيات المحتوى**: عدد القنوات المباشرة، الأفلام (VOD)، والمسلسلات
- 🌐 **معلومات الخادم**: URL، المنفذ، البروتوكول، IP، المنطقة الزمنية
- 📋 **سجل محلي**: حفظ آخر 50 فحصاً في المتصفح لإعادة الفحص السريع
- 🔗 **روابط جاهزة**: توليد رابط M3U وبوابة المشغل تلقائياً
- 🔐 **خصوصية تامة**: جميع الفحوصات تتم عبر الخادم، لا نخزن أي بيانات
- 🌙 **دعم RTL**: واجهة عربية كاملة من اليمين لليسار
- 📱 **متجاوب**: يعمل على الجوال والكمبيوتر

## 🎨 صيغ الإدخال المدعومة

1. **رابط get.php الكامل**:
   ```
   http://host:port/get.php?username=USER&password=PASS&type=m3u_plus
   ```

2. **رابط xtream://**:
   ```
   xtream://host:port/USER/PASS
   ```

3. **الصيغة المختصرة**:
   ```
   USER:PASS@host:port
   ```

4. **الإدخال اليدوي**: المضيف، المنفذ، اسم المستخدم، كلمة المرور

## 🛠️ التقنيات المستخدمة

- **Framework**: Next.js 16 (App Router)
- **Language**: TypeScript 5
- **Styling**: Tailwind CSS 4 + shadcn/ui
- **Font**: Cairo (Google Fonts - يدعم العربية واللاتينية)
- **Icons**: Lucide React
- **State**: React Hooks + localStorage

## 🚀 التشغيل المحلي

```bash
# تثبيت التبعيات
bun install

# تشغيل خادم التطوير
bun run dev

# فتح المتصفح على http://localhost:3000
```

## 📦 النشر

الطريقة الأسهل هي النشر على [Vercel](https://vercel.com):

```bash
vercel
```

أو ابني المشروع وأDeploy على أي استضافة تدعم Node.js:

```bash

bun run start
```

## 🔧 كيف يعمل؟

1. يرسل المستخدم رابط الاشتراك عبر الواجهة
2. يستقبل الـ API الطلب ويحلل الرابط لاستخراج (host, port, username, password)
3. يرسل الـ API طلباً إلى `player_api.php` على خادم Xtream
4. يتم تحليل الاستجابة وتنسيقها وإرجاعها للواجهة
5. تعرض الواجهة النتائج في بطاقات منظمة
6. عند الطلب، يتم جلب إحصائيات المحتوى عبر طلبات إضافية
